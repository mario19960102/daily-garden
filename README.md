# 🌿 每日花园 — 每日计划 + 积分养植物 + 海豚宠物

一个可爱的 PWA 网页应用，把每日计划、记账、植物大战僵尸图鉴兑换、海豚桌面宠物整合在一起。绿色可爱风，主要在 iPhone 上使用。

## ✨ 功能特性

### 📅 每日计划
- 添加/编辑/删除每日任务，按日期切换查看
- 勾选完成任务自动获得 **10 积分**
- 顶部进度条显示今日完成情况
- iOS 主屏幕角标提醒未完成任务数

### 💰 分类记账
- 收入/支出分类记账（正餐、外卖、零售 / 进货、房租、水电、餐饮、人工等）
- 每日统计总收入、总支出、净利润
- 近 7 天收支柱状图
- 净利润超 100 额外奖励 5 积分

### 🌱 植物大战僵尸图鉴（完整 48 种）
- 完整还原初代原版 48 种植物
- 每种植物的阳光价格 = 兑换积分价
- 兑换后植物点亮，进入"我的花园"展示
- 积分日志记录每笔获取/消耗

### 🐬 海豚桌面宠物
- SVG 绘制的可爱海豚，CSS 动画游动
- **喂食成长**：用积分换鱼虾喂食，获得经验升级
  - 🐟 小鱼：10 积分，+10 经验
  - 🦐 小虾：20 积分，+25 经验
  - 🦑 章鱼：50 积分，+80 经验
- **动画互动**：点击海豚会获得经验，可升级
- **情绪反馈**：根据今日计划完成情况表现不同情绪
  - 全部完成：😄 开心，快速游动吐泡泡
  - 部分完成：😊 悠闲，正常游动
  - 未完成：😴 期待，缓慢游动
  - 饱食度低：😢 饿了，消沉
- **成长形态**：Lv.5 解锁⭐，Lv.10 解锁👑，体型逐渐变大
- 陪伴天数、体重、饱食度、经验值完整档案

### 🎨 设计
- 绿色主色调（草绿 `#7CB342`），可爱风
- 圆角卡片、emoji 图标、柔和阴影
- iPhone 全屏适配，刘海安全区处理

## 📱 在 iPhone 上使用

### 方法一：本地服务器（推荐先用这个测试）

```bash
cd daily-garden
python3 -m http.server 8080
```

然后让 iPhone 和电脑连同一个 WiFi，用 iPhone Safari 打开 `http://电脑IP:8080`。

### 方法二：添加到主屏幕（像 APP 一样用）

1. 用 iPhone Safari 打开应用页面
2. 点击底部「分享」按钮
3. 选择「添加到主屏幕」
4. 从主屏幕图标启动，全屏体验，离线可用

### ⚠️ iOS 数据备份提示

iOS 系统**若 7 天未打开 PWA，会自动清除本地数据**。请：

- 定期打开 APP
- 通过菜单「导出数据备份」保存 JSON 文件
- 换设备或重装时用「导入数据恢复」

## 🗂️ 文件结构

```
daily-garden/
├── index.html       # 主应用（HTML+CSS+JS 单文件）
├── manifest.json    # PWA 清单配置
├── sw.js            # Service Worker 离线缓存
└── README.md        # 本说明文件
```

## 🛠️ 技术栈

- **纯 HTML + CSS + 原生 JS**（无框架，单文件部署）
- **IndexedDB** 本地存储（结构化数据）
- **PWA**（manifest + Service Worker）离线可用
- **SVG + CSS 动画** 实现海豚游动

## 📝 积分获取方式

| 行为 | 积分 |
|---|---|
| 添加任务 | +5 |
| 完成任务 | +10 |
| 净利润达标（超100） | +5 |
| 兑换植物 | -植物阳光价 |
| 喂海豚 | -10/-20/-50 |
